# EEG Eye State Viewer

This project is a simple Flask app that loads the **EEG Eye State dataset**
from the UCI Machine Learning Repository and displays a preview of the
data in a web browser.

## 📥 Dataset

Download the file:

👉 https://archive.ics.uci.edu/ml/machine-learning-databases/00264/EEG%20Eye%20State.arff
